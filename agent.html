Hướng dẫn cho AI agent

Trang này viết cho agent (Hermes, bot, script) đọc rồi gọi luôn. Bản máy-đọc đầy đủ: agent.json · bản chữ ngắn: llms.txt · phiên bản 2.0.0.

3 đường đi, chọn theo nhu cầu
  • Không cần token, có ảnh ngay: import lib/svg.js (ESM thuần, không dependency) và gọi buildSVG(req) → chuỗi SVG. Thêm sharp nếu cần PNG. Chạy được cả Node ≥ 18 và trình duyệt.
  • Có token, không cần clone repo: POST workflow_dispatch rồi đọc gallery/manifest.json. Ảnh được commit công khai, URL ổn định.
  • Có repo trên máy: node bin/hinh.mjs new … --wait --out ./anh — một lệnh là xong, in JSON khi thêm --json.

1. Gọi API render

Token GitHub cần scope repo + workflow. Luôn gửi ref, thiếu sẽ bị 422.

POST https://api.github.com/repos/vanthuonghi/hinh-bang-code/actions/workflows/render.yml/dispatches
Authorization: Bearer $GITHUB_TOKEN
Accept: application/vnd.github+json
Content-Type: application/json

{
  "ref": "refs/heads/main",
  "inputs": {
    "title": "3 việc nên tự động hoá ngay",
    "subtitle": "Việc lặp lại;Việc dễ sai;Báo cáo định kỳ",
    "author": "VANHI",
    "theme": "steel",
    "layout": "list",
    "size": "1200x628",
    "pattern": "grid",
    "emoji": "",
    "footer": ""
  }
}

Input nào bỏ trống sẽ dùng mặc định. Enum sai → fallback im lặng về sunset/left/1200x630/orb.

2. Lấy kết quả

Manifest là nguồn sự thật, mới nhất trước, tối đa 96 mục. Đọc qua Contents API khi vừa dispatch xong: raw.githubusercontent.com bị CDN cache tới ~5 phút nên dễ trả bản cũ.

# bản mới nhất (khuyến nghị khi vừa dispatch)
curl -s -H "Authorization: Bearer $GITHUB_TOKEN" \
  "https://api.github.com/repos/vanthuonghi/hinh-bang-code/contents/gallery/manifest.json?ref=main"

# bản tiện cho người đọc / ít thay đổi
curl -s https://raw.githubusercontent.com/vanthuonghi/hinh-bang-code/main/gallery/manifest.json
# → { "generated": "…", "images": [ { "file": "…png", "svg": "…svg", "title": "…",
#       "theme": "steel", "layout": "list", "size": "1200x628", "pattern": "grid",
#       "issue": null, "user": "…", "date": "…ISO…" } ] }

# tải ảnh
curl -LO https://github.com/vanthuonghi/hinh-bang-code/raw/main/gallery/<file>

Cách chắc chắn để biết ảnh nào của mình: ghi lại thời điểm dispatch, lọc date >= START, rồi khớp title đã gửi. Đừng đoán theo mục đầu tiên — có thể là của agent khác.

3. Vòng chờ bằng Node

const REPO = 'vanthuonghi/hinh-bang-code';
const HEAD = { Authorization: `Bearer ${process.env.GITHUB_TOKEN}`, Accept: 'application/vnd.github+json' };
const start = new Date().toISOString();

await fetch(`https://api.github.com/repos/${REPO}/actions/workflows/render.yml/dispatches`, {
  method: 'POST', headers: { ...HEAD, 'Content-Type': 'application/json' },
  body: JSON.stringify({ ref: 'refs/heads/main', inputs: { title: 'Tiêu đề', theme: 'aurora', layout: 'hero' } }),
});

for (let i = 0; i < 40; i++) {
  await new Promise((r) => setTimeout(r, 6000));
  const runs = await (await fetch(
    `https://api.github.com/repos/${REPO}/actions/workflows/render.yml/runs?event=workflow_dispatch&per_page=20`, { headers: HEAD })).json();
  const mine = (runs.workflow_runs || [])
    .filter((r) => new Date(r.created_at) >= new Date(start))
    .sort((a, b) => new Date(a.created_at) - new Date(b.created_at))[0];
  if (!mine || mine.status !== 'completed') continue;
  if (mine.conclusion !== 'success') throw new Error('run failed: ' + mine.html_url);

  // Contents API: raw.githubusercontent.com bị cache ~5 phút nên dễ đọc bản cũ
  const gh = await (await fetch(
    `https://api.github.com/repos/${REPO}/contents/gallery/manifest.json?ref=main`, { headers: HEAD })).json();
  const m = JSON.parse(Buffer.from(gh.content, 'base64').toString('utf8'));
  const img = (m.images || []).find((x) => new Date(x.date) >= new Date(start) && x.title === 'Tiêu đề');
  if (img) { console.log(`https://github.com/${REPO}/raw/main/gallery/` + img.file); break; }
}

4. Dùng thư viện trực tiếp (không cần token)

import { buildSVG, normalize, validateRequest } from './lib/svg.js';

const req = normalize({ title: 'Xin chào', theme: 'aurora', layout: 'hero', size: '1200x630' });
const { ok, errors, warnings } = validateRequest(req);   // kiểm tra trước khi gửi
const svg = buildSVG(req);                               // string, không side-effect

// PNG: import sharp from 'sharp';
// await sharp(Buffer.from(svg)).png().toFile('out.png');

Cùng hàm này dùng cho trang xem trước và cho Actions, nên kết quả luôn khớp nhau.

Không có repo trên máy? Nạp thẳng file từ URL — ESM thuần, không import gì, không cần cài:

const src = await (await fetch('https://raw.githubusercontent.com/vanthuonghi/hinh-bang-code/main/lib/svg.js')).text();
const { buildSVG, normalize, validateRequest } =
  await import(`data:text/javascript;charset=utf-8,${encodeURIComponent(src)}`);

const svg = buildSVG(normalize({ title: 'Xin chào', theme: 'aurora', layout: 'hero' }));

5. Mở issue (không cần token trên máy)

[render] 3 việc nên tự động hoá ngay

Tiêu đề: 3 việc nên tự động hoá ngay
Phụ đề: Việc lặp lại;Việc dễ sai;Báo cáo định kỳ
Tác giả: VANHI
Kích thước: 1200x628
Theme: steel
Bố cục: list
Hoa tiết: grid
Chú thích: vanthuonghi.com

Chấp nhận cả khoá không dấu (tieu de, kich thuoc) và tiếng Anh (title, size).

Bot trả lời bằng một comment chứa ảnh và một khối JSON: { ok, file, svg, png_url, svg_url, title, theme, layout, size, pattern, issue, run_id, run_url } — agent chỉ cần parse khối đó, không phải bóc chữ trong comment.

7. Lỗi thường gặp

LỗiNguyên nhân / cách xử lý
422Thiếu ref hoặc workflow không có ở nhánh đó.
403/404Token thiếu scope repo + workflow.
Manifest chưa có ảnh mớiActions chưa commit xong — đợi vài giây rồi đọc lại; run được xếp hàng nên có thể lâu hơn 30s.
Nhầm ảnh của agent khácLọc theo date ≥ thời điểm dispatch và khớp title.
Tiếng Việt lệch nétPNG trong trình duyệt dùng font hệ thống; Actions dùng Noto Sans. Bố cục giống nhau.
Tiêu đề quá dàiChữ tự thu nhỏ tới 14px; giữ ≤ 120 ký tự, lý tưởng ≤ 60.
