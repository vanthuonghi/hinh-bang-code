Tạo hình đẹp bằng code, không cần thiết kế

Nhập tiêu đề, chọn màu và bố cục — ảnh PNG tải về ngay trên máy bạn. Không cần đăng nhập, không token, không chờ. Muốn lưu vào thư viện công khai thì để GitHub Actions render hộ ~30 giây.

Nội dung

Chỉ tiêu đề là bắt buộc. Các ô còn lại để trống vẫn ra ảnh đẹp.

Câu ngắn thì chữ to. Dưới 60 ký tự là vừa đẹp cho hầu hết kích thước; dài hơn thì chữ tự thu nhỏ để không tràn.

Một câu mô tả ngắn nằm dưới tiêu đề.

Hiện thành dòng nhỏ phía trên (chữ in hoa, giãn cách). Với bố cục story và thẻ sticker nó thành avatar/nhãn — nên điền.

Dán yêu cầu nhanh (dạng văn bản hoặc JSON)
Nhận cả JSON như {"title":"…","theme":"aurora"}

Kiểu dáng

Bấm một mẫu để áp cả bộ màu + bố cục + kích thước. Sau đó chỉnh từng phần nếu muốn.

Đang chọn:

Hoa tiết nằm phía sau chữ, mờ nên không ảnh hưởng khả năng đọc.

Hiện thành biểu tượng lớn phía trên tiêu đề (trừ bố cục quote/sticker/terminal/story).

PNG được raster ngay trên máy từ cùng lib/svg.js mà GitHub Actions dùng — bố cục khớp, chỉ khác font hệ thống (Actions dùng Noto Sans). Phím tắt: Ctrl/⌘ + Enter để tải PNG.

Hướng dẫn cho AI agent (Hermes) đọc xong là gọi được

0. Tóm tắt 30 giây

  • Repo: vanthuonghi/hinh-bang-code · trang: vanthuonghi.github.io/hinh-bang-code
  • Máy đọc được danh mục máy-đọc: agent.json · bản chữ ngắn: llms.txt · trang hướng dẫn riêng: agent.html
  • Muốn ảnh ngay, không cần token: dùng lib/svg.js (thư viện JS thuần) hoặc tải PNG trên trang này.
  • Muốn ảnh lưu công khai + URL ổn định: gửi workflow_dispatch rồi đọc gallery/manifest.json.
  • Mọi input đều có fallback: sai theme/layout/size thì về mặc định, không bao giờ lỗi render.

1. Gửi yêu cầu render (REST)

Cần token GitHub với scope repo + workflow (repo public vẫn cần token để dispatch). Nhớ có ref, thiếu sẽ bị 422.

curl -X POST \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Accept: application/vnd.github+json" \
  https://api.github.com/repos/vanthuonghi/hinh-bang-code/actions/workflows/render.yml/dispatches \
  -d '{"ref":"refs/heads/main","inputs":{
        "title":"3 việc nên tự động hoá ngay",
        "subtitle":"Việc lặp lại;Việc dễ sai;Báo cáo định kỳ",
        "author":"VANHI",
        "theme":"steel","layout":"list","size":"1200x628","pattern":"grid"
      }}'
Chạy xong ~30 giây, kết quả nằm trong gallery/.

2. Lấy kết quả

Manifest là nguồn sự thật: mỗi mục có file, svg, title, theme, layout, size, pattern, issue, user, date.

# manifest (JSON, mới nhất trước)
# vừa dispatch xong thì đọc qua Contents API — raw bị CDN cache ~5 phút
curl -s -H "Authorization: Bearer $GITHUB_TOKEN" \
  "https://api.github.com/repos/vanthuonghi/hinh-bang-code/contents/gallery/manifest.json?ref=main"

# hoặc bản tĩnh (tiện cho người đọc, có thể chậm vài phút)
curl -s https://raw.githubusercontent.com/vanthuonghi/hinh-bang-code/main/gallery/manifest.json

# tải PNG theo tên file trong manifest
curl -LO https://github.com/vanthuonghi/hinh-bang-code/raw/main/gallery/<ten-file>.png

# theo dõi run (mới nhất trước) — lọc theo created_at để không nhầm run của agent khác
curl -s -H "Authorization: Bearer $GITHUB_TOKEN" \
  "https://api.github.com/repos/vanthuonghi/hinh-bang-code/actions/workflows/render.yml/runs?per_page=20"

3. Cách khác: CLI có sẵn trong repo

Node ≥ 20, không cần cài dependency. --wait chờ render xong rồi in URL; --out tải file về.

export GITHUB_TOKEN=...        # hoặc: gh auth login

node bin/hinh.mjs new --title "Tiêu đề" --subtitle "Phụ đề" \
  --theme aurora --layout quote --size 1080x1350 --pattern orb --emoji ✨ \
  --wait --out ./anh

node bin/hinh.mjs new --preset lo-trinh --title "Lộ trình 3 bước" --wait
node bin/hinh.mjs catalog --json     # toàn bộ theme/layout/size/pattern + nhãn
node bin/hinh.mjs list --n 10 --json
node bin/hinh.mjs get <ten-file.png> --out ./anh
node bin/hinh.mjs status --json

4. Cách khác: mở issue (dành cho người, không cần token trên máy)

Tiêu đề issue bắt đầu bằng [render]. Phần thân theo dạng Khoá: giá trị, mỗi dòng một khoá. Dấu tiếng Việt có/không đều được.

[render] 3 việc nên tự động hoá ngay

Tiêu đề: 3 việc nên tự động hoá ngay
Phụ đề: Việc lặp lại;Việc dễ sai;Báo cáo định kỳ
Tác giả: VANHI
Kích thước: 1200x628
Theme: steel
Bố cục: list
Hoa tiết: grid
Chú thích: vanthuonghi.com

Bot trả lời bằng comment chứa ảnh + khối JSON máy đọc (ok, file, svg, png_url, svg_url, title, theme, layout, size, pattern, issue, run_id, run_url) — agent chỉ cần parse khối đó.

5. Tạo ảnh cục bộ, không cần GitHub

Cùng một file lib/svg.js chạy ở Node và trình duyệt: buildSVG(req) trả về chuỗi SVG. Muốn PNG thì thêm sharp.

import { buildSVG, normalize, validateRequest } from './lib/svg.js';

const req = normalize({ title: 'Xin chào', theme: 'aurora', layout: 'hero', size: '1200x630' });
const { ok, errors, warnings } = validateRequest(req);
const svg = buildSVG(req);            // chuỗi SVG, không side-effect

// PNG (cần sharp): import sharp from 'sharp';
// await sharp(Buffer.from(svg)).png().toFile('out.png');

7. Quy ước & lỗi thường gặp

Hiện tượngNguyên nhân / cách xử lý
422 khi dispatchThiếu ref hoặc workflow không tồn tại ở nhánh đó. Dùng "ref":"refs/heads/main".
403/404Token thiếu scope repo + workflow, hoặc repo private mà token không có quyền.
Run xong nhưng manifest chưa có ảnhActions commit sau khi render; đợi thêm vài giây rồi đọc lại manifest. Nhiều run được xếp hàng, không chạy song song.
Ảnh bị coi là của agent khácLọc mục mới theo date >= thời điểm dispatch và khớp title đã gửi.
Chữ tiếng Việt trên ActionsWorkflow cài fonts-noto-core; PNG trong trình duyệt dùng font hệ thống nên nét chữ hơi khác.
Tiêu đề quá dàiChữ tự thu nhỏ tới 14px rồi vẫn có thể tràn với tiêu đề > 150 ký tự. Giữ dưới 120 ký tự.
