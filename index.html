🎨 Sinh hình bằng code

Miễn phí · không cần đăng nhập · không cần token. Nhập tiêu đề → tải PNG ngay trong trình duyệt (render trên máy bạn, không chờ Actions, không giới hạn số lượng). Muốn lưu ảnh vào gallery công khai của GitHub thì dùng nút bên phải (chỉ phần này mới cần tài khoản GitHub).

Tải PNG/SVG không cần gì cả — dán PAT ở đây chỉ khi muốn tạo issue GitHub ngay tại trang. Token nằm riêng trong trình duyệt của bạn.
PNG được raster ngay trên máy bạn từ cùng lib/svg.js — không server, không hàng chờ.
Ảnh thật do GitHub Actions render bằng sharp — cùng thư viện lib/svg.js nên khớp gần như tuyệt đối.

🤖 Cho agent / CLI (Hermes)

Hai cách gọi từ máy — không cần mở trang:

1. REST API (cần token scopes repo + workflow):

POST https://api.github.com/repos/vanthuonghi/hinh-bang-code/actions/workflows/render.yml/dispatches
{ "ref": "refs/heads/main", "inputs": { "title": "Tiêu đề", "subtitle": "Phụ đề", "size": "1200x630", "theme": "aurora", "layout": "quote" } }   // thiếu "ref" sẽ bị 422

# rồi lấy ảnh:
GET  https://api.github.com/repos/vanthuonghi/hinh-bang-code/contents/gallery/manifest.json
raw  https://github.com/vanthuonghi/hinh-bang-code/raw/main/gallery/<tên-file>.png

2. CLI (đi kèm repo, Node ≥20, không cần dependency):

export GITHUB_TOKEN=ghp_...   # hoặc: gh auth login
node bin/hinh.mjs new --title "Tiêu đề" --theme aurora --layout quote --size 1080x1350 --wait
node bin/hinh.mjs list --json
node bin/hinh.mjs get <tên-file.png> --out ./anh
